# Product map — November 7, 2026

Source baseline: `aaf68f373` (November 1 production release record). This table is based on source review. Metrics deployment was also inspected read-only at 2026-11-08 00:56 UTC (November 7 Pacific); other features were not verified live. Optional features require deployment configuration and external services. Current source and configuration take precedence over historical design notes.

Merv is a TypeScript/Cordis application. Domain providers own durable behavior; separate tool, HTTP and UI adapters expose it. PostgreSQL stores transactional state, blob storage holds evidence, Git holds code, and separate runners execute agents. The default configuration contains 61 plugin entries, including three disabled Feed entries. These are entrypoints, not independent product domains.

## Development context

- Recent October 30–November 1 work focuses on Board/Pi presence, gestures, drawing cadence, outcome editing, replay and sharing.
- Research coordinates work; Tasks, Experiments and Reflections own their workflow contracts; Reviews provides shared independent review; Code Work connects accepted work to generic Git storage.
- Pi, Fleet, Sandboxes and customer experiments are composed by deployment configuration, rather than all being enabled in the default local configuration.
- Metrics is implemented as an optional domain with separate tool and UI adapters. `deploy/render-config.mjs` loads it when `MERV_METRICS_TRACKIO_URL` and its credentials are configured; the Trackio server runs separately. Experiment contract 46 grants metric reads and running-producer connect/export actions when the tools are present.
- Claims and the standalone Consolidation plugin are retired. Existing claims became artifacts; current integration uses ordinary reviewed Git tasks.
- Older README composition counts and experiment contract numbers have drifted. This map uses `config/default.json`, current owner implementations and `deploy/render-config.mjs`.
- The marketing README's mailto-only description is also historical: the current site includes an early-access form backed by Attio, with optional Resend confirmation.
- Local development uses Node 22.13.1/npm 11.1.0 and PostgreSQL 17. The main suite is the full `tests/*.test.ts` glob; CI divides it into two shards. Deployment checks run separately.
