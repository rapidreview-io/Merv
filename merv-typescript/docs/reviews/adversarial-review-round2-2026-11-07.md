# Second adversarial review — November 7, 2026

Eight additional confirmed failures were reproduced and fixed after the [first ten findings](adversarial-review-2026-11-07.md). The review targeted concurrent file operations and cleanup, delayed browser work, retry identity, document bounds, notification acknowledgements and runner retention. All changes remain local; nothing was deployed.

The credential repair has a deliberate recovery limit: after a controller restart, a raw conversation is not retained if its launch credential fingerprints cannot be matched to recovered values. This also applies to already-spawned legacy ledger rows lacking fingerprints. Workspace capture/completion, session release and delivery of the already-redacted transcript continue. Exact credential values are not added to the ledger.

Customer Files has one provider in the current Main composition, so the request queue belongs in that service. It is an in-process ordering mechanism, not a distributed lock for hypothetical multiple active Main writers. Independent requests remain concurrent. This also replaces the first review's quota revision/retry machinery, leaving the unpublished Files migration 2 with only the completion receipt column.

The second full run took 71.60 seconds of test-runner time with builds running concurrently. The first review's isolated wall-time comparison was 130.61 → 63.54 seconds; do not interpret the second duration as a controlled timing comparison. Five new cases preserve the requested reduction while covering the new integration failures. See [the test guide](../../tests/README.md).

Every listed failure has an executable before-fix reproduction or a regression observed failing before repair. Focused checks passed for Files (15), customer service (7), Paper/Research (6), runner (21) and the new Board lifecycle cases (2). The combined main suite passed **393/393**, with no failures or skips; server and browser typechecks/builds also passed. After the final short-credential refinement, all 24 runner/secrets tests passed with no skips; server typecheck and build passed again. CI formatting and diff whitespace checks passed. Deployment/Python and website gates passed in the first review; their code did not change in this pass.

The reproduction programs use synthetic credentials, local PostgreSQL, deterministic provider stand-ins and local child processes. No real mail, payment, rented machine, external agent run or production write was needed. This is a broad functional adversarial review, not an exhaustive security certification. Unproven suspicions were omitted.

Responsibilities remain with the existing plugins: Customer Files orders its storage mutations, Customer Service owns notification delivery, Research owns command replay, Paper owns document limits, Runner owns retention/redaction and the browser owns view/request scope. No new plugin or dependency was introduced. Across both reviews, the working changes remove approximately 42,000 net repository lines, including new tests and documentation. Most regressions extend existing cases; five new cases cover distinct integration failures.
