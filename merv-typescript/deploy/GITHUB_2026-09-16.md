`iss=https://github.com/login/oauth`. The original strict query parser rejected
this field. Commit `cb720b0c` accepts this exact issuer when present and rejects
wrong, empty, or duplicate issuers and unknown callback fields. State and browser
binding checks remain in force.

## Recovery

For this initial activation, restoring `typescript.env` from the activation backup
and recreating the current TypeScript container disables GitHub. It does not
uninstall the App or revoke GitHub grants. Do not restore the disabled environment
after connections have been created without a deliberate recovery plan; retain
`enabled.env` and its encryption key. No database restore is needed to undo this
configuration change.

This release stores repository references and checks private-repository access.
Git clone/fetch/push, PR creation, and lending GitHub tokens to runners are outside
this implementation.
